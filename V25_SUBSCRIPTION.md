# V25 – School Subscription & Trial Management

- Existing schools remain `legacy` and retain current access after migration.
- Newly onboarded schools start with a 30-day trial.
- Super Admin can start/reset trials, activate a plan, extend a period, grant grace, suspend/cancel a subscription, or restore legacy access.
- Expired trial/subscription blocks new staff and student logins without deleting school data.
- Grace period allows temporary continued login.
- All subscription changes are audit logged.
- This release does not process payments; payment-provider integration can be added later.
